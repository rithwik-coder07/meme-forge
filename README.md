# MemeForge 🎭
### AI-Powered Meme Generator Web Application

MemeForge is a web application that allows users to create funny and viral memes using Artificial Intelligence. Users can pick from real meme templates, describe their idea, and let AI generate punchy captions automatically.

---

## Features
- AI-powered caption generation using Google Gemini
- 20+ real meme templates from Imgflip API
- User authentication (Sign up / Sign in)
- Download memes as PNG
- Responsive and professional UI
